ACTIVITY 15 // METADATA ANALYSIS

METADATA
TRACE

Análisis de metadatos con ExifTool a partir de dos archivos de origen: un documento DOCX y una fotografía JPG. El ejercicio identifica propiedades del documento, atributos de captura y datos GPS, y relaciona estos hallazgos con la privacidad y el manejo responsable de archivos digitales.

INPUT FILES
FILE 01 // DOCX

Propiedades documentales

Se revisaron campos como clasificación, plantilla utilizada, tiempo de edición, compañía, creador, última modificación y fecha de creación del documento analizado.

FILE 02 // JPG

Datos de captura

Se identificaron valores EXIF vinculados con la fotografía, incluidos ISO, longitud focal, uso del flash y fecha de captura.

GPS // LOCATION

Geolocalización

La muestra contenía coordenadas GPS que fueron convertidas a formato decimal y contrastadas con una ubicación geográfica en el Reino Unido.

PRIVACY // CLEANUP

El documento registra la eliminación de los metadatos de la imagen de muestra, reforzando la importancia de revisar los datos embebidos antes de compartir archivos.

03 // SECURITY TAKEAWAY

WHY METADATA MATTERS
15

Los archivos pueden revelar más de lo que muestran.

Los metadatos pueden incluir información de autoría, herramientas y plantillas, fechas de actividad, características del dispositivo y ubicación. La revisión con ExifTool ayuda a reconocer estos datos y permite decidir qué información debe conservarse o retirarse antes de distribuir un archivo.

La evidencia adjunta conserva el informe original y sus respuestas completas. Esta página resume el alcance y los principales resultados para su consulta dentro del portafolio.

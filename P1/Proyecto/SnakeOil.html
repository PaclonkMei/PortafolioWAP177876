01 // EXECUTIVE SUMMARY

PROJECT OVERVIEW

Durante la práctica identificamos la superficie expuesta de Snake Oil, analizamos el comportamiento de su API REST y demostramos el impacto de una inyección de comandos del sistema operativo. A partir del acceso inicial se obtuvo una shell reversa, se revisó el código fuente, se localizaron credenciales almacenadas en texto plano y se accedió al sistema mediante SSH.

El compromiso avanzó hasta privilegios de superusuario debido a permisos administrativos excesivos. Finalmente se configuró persistencia por medio de una clave SSH autorizada y se comprobó su funcionamiento después de reiniciar la máquina.

04 // SECURITY FINDINGS

ROOT CAUSE ANALYSIS
F-01 // CWE-78

Inyección de comandos

La API procesaba entrada controlada por el usuario dentro de un shell del sistema sin una validación suficientemente estricta, permitiendo ejecución de comandos ajenos a la función prevista.

SEVERITY // CRITICAL
F-02 // CWE-798

Credenciales incrustadas

Las credenciales del usuario Patrick estaban almacenadas directamente en el código fuente, lo que permitió convertir el acceso inicial en una sesión SSH estable.

SEVERITY // HIGH
F-03 // SUDO CONFIG

Privilegios administrativos excesivos

Los permisos disponibles para la cuenta comprometida reducían casi por completo la separación entre un usuario regular y root.

SEVERITY // CRITICAL

05 // MITIGATION MATRIX

DEFENSIVE CONTROLS
01

Eliminar ejecución insegura mediante shell

Evitar shell=True cuando exista entrada dependiente del usuario y separar comandos de datos mediante argumentos explícitos.

02

Validación estricta de entradas

Aplicar listas blancas, restricciones de formato y pruebas específicas sobre parámetros que alcancen funciones del sistema operativo.

03

Gestión segura de secretos

Retirar contraseñas, tokens y llaves del código fuente y utilizar mecanismos dedicados de gestión de secretos.

04

Principio de menor privilegio

Restringir con precisión los comandos ejecutables mediante sudo y utilizar cuentas de servicio sin permisos administrativos.

05

Fortalecer sesiones y monitoreo

Gestionar de forma consistente los tokens de sesión y registrar eventos anómalos de autenticación, enumeración y acceso a endpoints sensibles.

08 // CONCLUSION

LESSONS LEARNED
01

Snake Oil permitió observar cómo varias malas prácticas independientes pueden encadenarse hasta producir un compromiso total. La inyección de comandos abrió el acceso inicial, pero la exposición de credenciales y los privilegios administrativos excesivos amplificaron significativamente el impacto.

La práctica también mostró que una prueba de penetración no termina al obtener una consola: la post-explotación, la validación de persistencia y el análisis de mitigaciones son esenciales para comprender el riesgo completo y convertir el ejercicio ofensivo en mejoras defensivas concretas.
